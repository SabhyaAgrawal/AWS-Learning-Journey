# Amazon S3 - Hands-on Lab

## Overview

In this project, I explored Amazon S3 by creating a bucket, uploading files, managing objects, and learning the basics of cloud storage. This hands-on lab helped me understand how Amazon S3 is used to securely store and manage data in AWS.

---

## Objective

The objective of this project was to:

- Create an Amazon S3 bucket
- Upload files to the bucket
- Create folders
- Download objects
- Delete objects
- Configure bucket permissions
- Understand S3 storage concepts

---

## AWS Service Used

- Amazon S3

---

## Steps Performed

### Step 1: Open the AWS Console

- Logged in to the AWS Management Console.
- Opened the **Amazon S3** service.

---

### Step 2: Create a Bucket

- Clicked **Create bucket**.
- Entered a unique bucket name.
- Selected the AWS Region.
- Left the default settings.
- Clicked **Create bucket**.

Bucket Name:

```
my-first-s3-bucket
```

---

### Step 3: Upload Files

- Opened the bucket.
- Clicked **Upload**.
- Selected files from my computer.
- Uploaded the files successfully.

---

### Step 4: Create a Folder

Created a folder inside the bucket named:

```
documents/
```

Uploaded additional files into the folder.

---

### Step 5: View Objects

Verified that all uploaded files appeared inside the bucket.

---

### Step 6: Download Files

Selected an object and downloaded it to my local computer.

---

### Step 7: Delete Objects

Deleted unwanted files from the bucket.

---

### Step 8: Delete the Bucket

- Removed all objects.
- Deleted the bucket successfully.
